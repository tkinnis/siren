# Siren Documentation

Welcome to the **Siren** documentation. Siren is a fast, keyboard-friendly Markdown viewer and editor designed for macOS, built with Flutter.

Whether you are browsing documentation, reviewing technical specifications, or taking notes, Siren provides an instant rendered preview alongside a dedicated raw editor with a line number gutter.

## Quick Start

### Opening a Workspace
When launching Siren, you can open any folder or Markdown file:
- **Open File**: Press `Cmd+O` or select **File > Open File...**
- **Open Folder**: Press `Cmd+Shift+O` or select **File > Open Directory...** to set your workspace root. The sidebar File Explorer will automatically index and display all documents in that folder.

### Switching Between Rendered and Raw Views
- Press `Cmd+E` (or click the toggle icon in the top toolbar) to switch between **Rendered Mode** and **Raw Markdown Mode**.

### Quick Open (Fuzzy Finder)
- Press `Cmd+P` anywhere in Siren to open the fuzzy file finder. Type any part of a filename or path to jump directly to that document.
