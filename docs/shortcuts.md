# Siren Keyboard Shortcuts

Siren is built with a keyboard-first philosophy. This document lists all available keyboard shortcuts for macOS.

---

## Navigation & Workspace

| Action | Shortcut | Description |
| :--- | :---: | :--- |
| **Toggle Render / Raw View** | `Cmd+E` | Switch between formatted rendered view and raw Markdown with gutter |
| **Toggle Dark / Light Theme** | `Cmd+Shift+D` | Instantly switch between light and dark themes |
| **Toggle Sidebar** | `Cmd+B` | Show or hide the sidebar (Explorer & Outline) |
| **Back in History** | `Cmd+[` or `Alt+Left` | Navigate to the previous document in tab history |
| **Forward in History** | `Cmd+]` or `Alt+Right` | Navigate forward in tab history |
| **Open Settings** | `Cmd+,` | Configure appearance, theme mode, and file indexing patterns |

---

## File & Tab Management

| Action | Shortcut | Description |
| :--- | :---: | :--- |
| **Open File** | `Cmd+O` | Open a Markdown file via system file picker |
| **Open Folder** | `Cmd+Shift+O` | Open a directory as the workspace root |
| **New Document** | `Cmd+N` | Create a new untitled document |
| **Close Tab** | `Cmd+W` | Close the currently active document tab |
| **Reopen Closed Tab** | `Cmd+Shift+T` | Restore the most recently closed tab |
| **Switch to Tab 1-9** | `Cmd+1` – `Cmd+9` | Jump directly to tab at the given index |

---

## Search & Discovery

| Action | Shortcut | Description |
| :--- | :---: | :--- |
| **Quick Open (Fuzzy Finder)** | `Cmd+P` | Search and open files across the workspace |
| **Find in File** | `Cmd+F` | Open the in-document search bar |
| **Global Workspace Search** | `Cmd+Shift+F` | Full-text search across all workspace Markdown files |
| **Next Match** | `Enter` | Jump to the next match in Find in File |
| **Previous Match** | `Shift+Enter` | Jump to the previous match in Find in File |
| **Dismiss Search / Modals** | `Escape` | Close the find bar or Quick Open modal |

---

## View, Zoom & Reload

| Action | Shortcut | Description |
| :--- | :---: | :--- |
| **Increase Font Size** | `Cmd++` or `Cmd+=` | Enlarge document body and raw text font |
| **Decrease Font Size** | `Cmd+-` | Reduce document body and raw text font |
| **Reset Font Size** | `Cmd+0` | Reset font size to default (15.0) |
| **Reload File** | `Cmd+R` | Reload active document from disk |

---

## Document Navigation (Rendered Mode)

| Action | Interaction |
| :--- | :--- |
| **Jump to Heading** | Click any heading in the **Outline View** |
| **Open Link** | Click any relative Markdown link |
| **Follow In-Document Anchor** | Click an anchor link (e.g. `#section-heading`) to scroll smoothly |
